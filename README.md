# Kotlin-Game

## Cyberpunk Arena (Godot 4.4, Android)

A third-person 3D action game featuring the cyberpunk warrior character in a white arena.

- `cyberpunk_arena/`: complete Godot 4.4.1 project. See [its README](cyberpunk_arena/README.md) for controls, build steps and tests.
- `release/CyberpunkArena-debug.apk`: signed debug APK (arm64-v8a and armeabi-v7a).
- `release/CyberpunkArena-godot-project.zip`: the project as a ZIP.

`assets.zip` holds the original 2D asset pack. The game does not use it.
